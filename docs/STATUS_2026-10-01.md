## Known issue found in review (not fixed)

Station-scoped service messages are matched by station **name**. PIDS use MTR's station name (`client/live/BoardBuilder.java:63`), but the terminal (`client/wayfinding/PassengerTerminalScreen.java:154-171`) and the station information board (`client/wayfinding/WayfindingSignRenderer.java:154`) use the *resolved* name, in which a manual name override wins. A terminal or board with a manual name therefore loses that station's messages while the PIDS beside it shows them. Proposed fix (not one line, so left for 1.3.1): look messages up by the MTR station name when the block resolves an MTR station, and fall back to the manual name only when it does not.
